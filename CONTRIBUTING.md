# Contributing

Keep Lite deployable as plain static files: no server runtime, database, build service, or required package installation for listeners.

Run from the repository root:

```sh
npm test
```

Changes to `js/52hertz.js` should originate in the standalone [52hertz.js](https://github.com/pournasseh/52hertz.js) repository and be synchronized intentionally for a Lite release.
